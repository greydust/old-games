# WDRAGON 本機版本比較

使用 `python tools/compare_wdragon_versions.py` 重現。
原始遊戲只讀；逐檔雜湊、逐 byte 差異、逐武將差異與韓文說明轉碼保存在
`local/extracted/WDRAGON/versions/`。比較基準是本機 `WDRAGON`，不宣稱它是唯一官方原版。

## Dragon hydeeric2002 ptt

主遊戲目錄與基準有 59 個同名檔逐 byte 相同，4 個不同，6 個缺少。
不同的是 `KI.EXE`、`PLAY.BAT`、`SAVE.DAT`、`SINARIO.DAT`。
地圖、頭像、音樂與對話等 59 個檔案完全相同。

`KI.EXE` 同長，只有原檔位址 `0x775D`、`0x775E`、`0x7760` 三個 bytes 不同，
其效果是把武將表頭「統率」改成「謀略」。其餘 bytes 完全相同，因此此檔未修改戰鬥程式。
不能把欄位更名當成能力計算機制改變。

附帶劇本分為四組，每組四章，另有各組的「(改)」副本：

| 組 | 章節 |
| --- | --- |
| 1–4 | 黃巾之亂、官宦爭權、董卓亂政、曹操崛起 |
| 5–8 | 呂布歸天、官渡之戰、隱伏新野、赤壁之戰 |
| 9–12 | 伏龍鳳雛、蜀地偏安、三國鼎立、劉禪即位 |
| 13–16 | 六出祁山、姜維繼志、唇亡齒寒、穿越時空 |

主目錄目前使用第 5–8 章。包內說明要求以複製替換 `SINARIO.DAT` 更換一組四章。
實際資料夾有四組，雖然附帶遊戲說明寫「3 個劇本資料夾」，以實際檔案為準。

「(改)」與同組未改檔比較，各章武將記錄改動數（每章最多127個具名槽）：

| 組 | 各章改動武將數 | 城池記錄改動數 |
| --- | --- | --- |
| 1–4 | 114、103、117、113 | 全部 0 |
| 5–8 | 120、117、117、119 | 全部 0 |
| 9–12 | 119、120、122、118 | 全部 0 |
| 13–16 | 111、105、101、1 | 全部 0 |

主要更動武術、第二能力（本包表頭為謀略）、政治及兩個適性欄；亦有少量狀態欄差異。
例如第1章張梁三能力由 8/7/8 改為 12/10/8，張寶由 10/4/3 改為 10/11/9；
不是所有武將都提高，何進由 7/2/9 改為 5/1/5。

`原劇本/SINARIO.DAT` 與本機基準僅差4 bytes，位於第一章李暹的第二姓名欄。
`原劇本(改)` 相對 `原劇本` 改24 bytes：23個適性欄 byte，以及第一章賈詡第二能力由6變13。
其中適性實際兵種名稱映射未完成，不將其直接命名為某種兵種能力。

存檔差異只證明遊玩狀態不同，不算作規則修改。附帶模擬器、設定檔、編輯器等也不算遊戲機制修改。

## WRJ hydeeric2002 ptt

主目錄與基準有31個同名檔完全相同、17個不同、21個缺少。
改動包括主程式、劇本、對話、戰術地圖、世界地圖、部分頭像與圖像。
新增韓文相關字型檔及編輯工具。名稱欄的編碼／字型映射未核對，不直接以Big5讀取人物名稱作比較。

附帶文字以 CP949 解碼，標題為「와룡전 헬버전 by 강펠레」，
日期 2013-03-13、說明修訂 2013-09-27。以下為**作者說明，尚未逐項完成程式驗證**：

- 電腦可能在宣戰前將兵力預先移到邊界。
- 依玩家狀況提高電腦兵力、士氣恢復速度與移動速度，陷入劣勢時額外強化。
- 提高進攻傾向、軍團移動 AI，以及選將編成效率。
- 資金上限從655000提高至3000000。
- 含先前的海戰能力套用、移除援軍請求彈窗等修改。
- 預設劇本含高句麗；改用 `SINARIO_original.DAT` 可使用不含高句麗的版本。

難度依作者說明由低至高為：`KI.EXE` 普通、`KI_light.EXE` 困難、
`KI_medium.EXE` 很困難、`KI_hard.EXE` 極難。不要將 light 理解成簡單。
三個變體均與預設主程式同長，分別有290、307、325個不同 bytes，
差異集中於 `0x11164` 之後；每個參數的實際作用尚未確認。

作者提醒此改版搭配其整套檔案使用；也提供僅替換主程式套用既有劇本／存檔的說明。
本次沒有執行包內遊戲或編輯器，也沒有覆蓋任何原始檔。
